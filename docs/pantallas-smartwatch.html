CodeRingView es el anillo de progreso (remaining/period; aquí 12/30 = 252°). El código se regenera con Totp.generate() (RFC 6238, HmacSHA1) cada vez que el contador de 30 s cambia; el countdown y el anillo se actualizan cada segundo. FLAG_KEEP_SCREEN_ON mantiene la esfera encendida.

Si el QR no se lee (bajo contraste, desenfocado) o la URI no es otpauth://totp con secret, OtpauthParser.parse() devuelve null y el escaneo continúa sin cambios visibles. En el emulador se resuelve reenviando una captura más grande a la cámara virtual (Extended Controls → Camera → Set Image).

Resumen de mapeo pantalla → código

Pantalla 1 Permiso cámara → cameraPermission.launch(Manifest.permission.CAMERA) Pantalla 2 Escaneo QR → startCamera() + CirclePreviewView + ScanReticleView + ML Kit Pantalla 3 Panel del código → showCodePanel() + updateCode() (tick 1 s, CodeRingView) Pantalla 3b Rotación 30 s → Totp.generate() con nuevo counter = tiempo/period Pantalla 4 Restablecer → confirmReset() → MaterialAlertDialogBuilder Pantalla 5 Sin cámara → selector == null → Toast "Este dispositivo no tiene cámara" Pantalla 6 QR inválido → OtpauthParser.parse() == null → sigue en Pantalla 2
